# AXIOM AI v0.3.0-beta.8 — Release Notes

**Version:** `0.3.0-beta.8`
**Tag:** `v0.3.0-beta.8`
**Release channel:** Beta prerelease
**Repository:** https://github.com/manit6752025/AXIOM-AI

Beta.8 builds on beta.7 with paginated and searchable history across the API, CLI and Control Center, new global CLI output controls, a full website redesign, and refreshed branding.

## Highlights

### 1. Pagination and Search Across Workspace Data

- Added bounded, cursor-based pagination and search for saved workflows through the API, CLI and Control Center.
- Added paginated, searchable Model Studio job history, exposed through the API.
- Added paginated dataset and workspace event inventories in the API, with typed client helpers.
- Runtime traces can now be paged, searched and loaded from older history in the Runtime page.
- Trace history stays metadata-only. Prompt and response bodies are still not recorded.
- Kept the existing array-based client API working while adding the new page helpers.
- Preserved the default dataset inventory page size.

### 2. CLI Improvements

- Added global verbosity, quiet and JSON error modes.
- Added validation for workflow search and cursor bounds.
- Fixed a missing logging import affecting the global verbose option.
- Documented the global output controls and error schema.

### 3. Website Redesign

- Redesigned the website with a centred, full-screen layout, typed headlines and a galaxy hero.
- Added new pages: Integrations, Workflows, Downloads, Docs, Roadmap, Security and Community.
- Added a dedicated Native Engine page explaining AXIOM's independent inference runtime.
- Added native model pull and AXIOM-owned generation commands to the website docs.
- Refreshed the branded 404 page.
- Unified the dark theme and made all pages fluid and responsive.
- Fixed navigation wrapping, downloads layout and the Saturn brand mark.
- Updated landing page end-to-end tests for the new site.

### 4. Branding and Documentation

- Added a unified AXIOM documentation banner and refined the orbital monogram.
- Updated the README banner image.
- Documented workflow cursor pagination, runtime trace paging and retention, and workspace collection pagination contracts.
- Updated the roadmap with verified pagination progress and preserved the R121–R140 scope.

### 5. Release Engineering and CI

- Added a workflow that syncs `main` into all branches.
- GitHub Pages now deploys only on version tags or manual dispatch.
- Nightly CI now installs native inference test dependencies.
- Aligned static release contracts with the paged trace and workflow APIs.
- Added release tests that enforce pagination across API, CLI and GUI.
- Fixed JSON and Python errors found during release prep.
- Removed `website/apply.sh`.

## Known Limitations

- Native Engine support still depends on checkpoint architecture, tokenizer, device and installed optional dependencies.
- Hardware-fit estimates are advisory.
- Runtime GUI history is held in browser memory only.
- The macOS DMG and tarball packages are not Apple Developer ID signed or notarized.
- Downloadable assets and checksums are authoritative only after tag-triggered workflows complete successfully.
- The MCP server remains default-deny, and cloud LLM requests remain consent-gated.

## Installation

```bash
python -m pip install --upgrade --pre axiom-all
axiom version
```

For platform packages and checksums, see the [AXIOM GitHub Releases](https://github.com/manit6752025/AXIOM-AI/releases) page.
