AXIOM / WORKFLOWS

Plan work. Run it. Measure results.

AXIOM connects hardware-aware training plans, experiment history, optional fine-tuning and offline evaluation into repeatable engineering workflows.

← Back to overview
01 / TRAINING

Plan before you spend compute.

Generate hardware-aware training plans, choose methods such as LoRA or QLoRA where supported, and keep experiment context with your workspace.

axiom train plan 7 --method qlora

Plans are estimates. Actual memory use and performance depend on model architecture, sequence length, hardware, quantisation and runtime.

02 / EVALUATION

Measure outputs offline.

Score precomputed predictions, compare results against a baseline and gate regressions without requiring an online model call for every evaluation.

axiom evaluation run
03 / AGENT OPTIMISER

Match configuration to workload.

Agent Optimizer includes eight workload profiles that select quantisation and build a runtime bundle. Review the generated profile and runtime requirements before applying it.

axiom optimize profiles
