AXIOM / SECURITY

Privacy and security are part of the design

AXIOM favours local-first workflows, explicit integrations and inspectable source. Security still depends on how you configure, expose and operate each component.

← Back to overview
LOCAL-FIRST

Keep work close to your machine.

Local workflows are central to AXIOM. Review each feature's network requirements and local file access before use.

EXTERNAL PROVIDERS

Understand the boundary.

Cloud and OpenAI-compatible providers receive requests outside your machine. Check provider selection and endpoint settings before sending prompts or data.

CONTAINERS

Deploy with care.

The container guide documents the unprivileged runtime, loopback port mapping and workspace mount precautions. Do not expose the workspace API publicly without a separate security review.

REPORT A VULNERABILITY

Use responsible disclosure.

Do not post exploitable details or credentials in public issues. Use GitHub private vulnerability reporting when available.
