AXIOM / COMMAND LINE

A practical command surface for AI work

AXIOM's CLI gives scripts, developers and operators a direct interface to model, dataset, system, training, inference and workspace operations.

← Back to overview
START HERE

Initialise and diagnose.

axiom init my-ai
cd my-ai
axiom doctor
axiom guide

Create a workspace, run diagnostics and get context-aware next-step guidance.

MODELS & HARDWARE

Inspect before loading.

axiom model inspect ./models/my-model
axiom model info Qwen/Qwen2.5-0.5B-Instruct
axiom system info

Review local model assets, remote metadata and machine resources.

DATASETS

Validate your inputs.

axiom dataset validate ./data/train.jsonl
axiom dataset stats ./data/train.jsonl

Find data quality issues and inspect aggregate dataset characteristics.

TRAINING & EVALUATION

Plan, then measure.

axiom train plan 7 --method qlora
axiom evaluation run

Generate hardware-aware plans and evaluate prediction outputs offline.

ENGINE & PROVIDERS

Operate local inference.

axiom engine status
axiom infer service start
axiom llm providers

Inspect native runtime status, manage local services and view provider configuration.

AGENTS & TOOLING

Extend your environment.

axiom mcp serve
axiom tools list

Expose permissioned local tools to AI agents and inspect developer integrations.

Commands and optional extras vary by installation. Refer to the current CLI help and release documentation before relying on a particular command.
