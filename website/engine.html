AXIOM / AXIOM ENGINE

Local inference. Explicit control.

AXIOM includes a native local inference path and a broader engine programme focused on model execution, runtime visibility and predictable lifecycle operations.

← Back to overview
NATIVE INFERENCE

Run models locally.

The project README describes direct local inference through PyTorch, separate from an Ollama dependency and without relying on model.generate.

OLLAMA OPERATIONS

Manage a local service.

AXIOM provides managed loopback service operations, cancellable model pulls, streamed output with stop/cancel, loaded-model inventory, metadata inspection and unload without deleting weights.

GGUF & MODEL STUDIO

Work with open model formats.

Model Studio supports GGUF search and installation workflows, with local model conversion paths described in the project feature map.

UNIFIED CLIENT

One client across providers.

Use the unified LLM client for AXIOM Native Engine, Ollama and supported cloud or OpenAI-compatible providers. Review provider configuration and consent before connecting external services.
