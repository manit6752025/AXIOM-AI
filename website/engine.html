AXIOM / AXIOM ENGINE

A local-first runtime direction

AXIOM Engine is the native runtime initiative: local model execution, explicit lifecycle controls and a consistent interface for inference workflows.

← Back to overview
LOCAL EXECUTION

Keep compute close.

The project is designed around local model assets and local execution, with cloud providers requiring explicit user choice rather than silent fallback.

MODEL SUPPORT

Build around open formats.

GGUF and local model workflows are part of the engine direction. Compatibility and runtime support should be verified against each release.

LIFECYCLE

Make runtime state visible.

Start, inspect, stop and unload operations are central design goals for a controllable local service.

STATUS

In active development.

Engine capabilities evolve with the development branch. Consult the roadmap and release notes for verified implementation status; this page does not imply every planned capability is complete.
