AXIOM

Plan local AI work before it runs.

AXIOM is a command line tool for inspecting your models, datasets and hardware, then planning AI jobs on your own machine.

Install AXIOM

Run these first.

$axiom system info

See what this machine can run.

It runs on your machine. It plans before it spends. It tells you what it found.

Get AXIOM

$ git clone https://github.com/manit6752025/AXIOM-AI
$ cd AXIOM-AI && pip install -e .
$ axiom system info
