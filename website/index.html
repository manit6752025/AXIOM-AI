Get AXIOM ↗

Plan local AI work before it runs.

AXIOM is a local-first, open source toolkit for inspecting models, datasets and hardware, then planning AI work on your own machine.

Get AXIOMRead the docs
python -m pip install --upgrade --pre axiom-all

Start with these commands.

$axiom doctor

Run diagnostics on your workspace.

It runs on your machine. It plans before it spends. It tells you what it found.

Everything in AXIOM

Platform

AXIOM combines the checks you need before a run with the tools you use to build, evaluate and operate local AI systems.

Control Center

Launch AXIOM's browser-based Control Center from your own computer. It brings project workflows into a visual interface while the local service handles workspace operations.

Open page

AXIOM Engine

AXIOM Native Engine: independent local model inference with PyTorch, trusted model files, streaming generation, memory planning and optional external runtimes.

Open page

Integrations

AXIOM can serve as a local AI workspace for people and agents. Choose a provider deliberately, understand the network boundary and keep permissions explicit.

Workflows

AXIOM connects hardware-aware training plans, experiment history, optional fine-tuning and offline evaluation into repeatable engineering workflows.
