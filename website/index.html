Install AXIOM ↓ See what it checks ↓

Three checks before training.

Get a clear picture of your inputs and machine. These checks inspect; starting a training run takes a separate command.

  1. 01

    Inspect a model

    See what is in the model folder and what AXIOM can identify.

  2. 02

    Validate the data

    Find malformed JSONL lines and duplicate records before training.

  3. 03

    Check your computer

    Review your available CPU, memory, GPU, and VRAM before choosing a model.

Install on your machine.

Choose your platform, run the command, then enter axiom to see the starter list.

Prefer APT? Debian, Ubuntu, and Linux Mint
64-bit Linux 
curl -fsSLo /tmp/axiom-archive-keyring.gpg https://manit6752025.github.io/AXIOM-AI/apt/axiom-archive-keyring.gpg
sudo install -Dm0644 /tmp/axiom-archive-keyring.gpg /usr/share/keyrings/axiom-archive-keyring.gpg
echo 'deb [arch=amd64 signed-by=/usr/share/keyrings/axiom-archive-keyring.gpg] https://manit6752025.github.io/AXIOM-AI/apt stable main' | sudo tee /etc/apt/sources.list.d/axiom.list
sudo apt update
sudo apt install axiom-ai
