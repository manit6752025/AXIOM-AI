Install AXIOM your way

Choose the installation route that fits your environment. AXIOM is in beta; check release notes, platform support and checksums before installing.

PYTHON / ALL PLATFORMS

Install from PyPI.

Install the current pre-release package, then verify the CLI is available.

python -m pip install --upgrade --pre axiom-all
axiom version
View package ↗
MACOS / LINUX

Use the installer.

curl -fsSL https://raw.githubusercontent.com/manit6752025/AXIOM-AI/main/installers/install.sh | bash
axiom version

Installer places axiom in ~/.local/bin. Add it to PATH if needed.

WINDOWS POWERSHELL

Install on Windows.

irm https://raw.githubusercontent.com/manit6752025/AXIOM-AI/main/installers/install.ps1 | iex
axiom version

Reopen PowerShell if the updated PATH is not picked up.

DEBIAN / UBUNTU / LINUX MINT

Use the signed APT repository.

curl -fsSLo /tmp/axiom-archive-keyring.gpg https://manit6752025.github.io/AXIOM-AI/apt/axiom-archive-keyring.gpg
sudo install -Dm0644 /tmp/axiom-archive-keyring.gpg /usr/share/keyrings/axiom-archive-keyring.gpg
echo 'deb [arch=amd64 signed-by=/usr/share/keyrings/axiom-archive-keyring.gpg] https://manit6752025.github.io/AXIOM-AI/apt stable main' | sudo tee /etc/apt/sources.list.d/axiom.list
sudo apt update
sudo apt install axiom-ai

APT package is for 64-bit Intel and AMD systems.

CONTAINERS & RELEASE ASSETS

Run verified container images or download a release.

Core, inference, training and full-extras images are published through GitHub Container Registry. The core image supports Linux AMD64 and ARM64; optional inference/training images have their own platform constraints.
